# 旅遊盲盒

假日不知道去哪？依車程或行駛距離，從台灣本島 162 個地點中隨機抽出今天的目的地。

**開啟：** https://jack1214w.github.io/travel-blindbox/

- 五大類：海洋景觀、山區風光、街區小鎮、人文探索、市集美食
- 自動定位出發地（也可選縣市與鄉鎮區、常用地點或貼上座標）
- 車程依 OSRM 實際道路計算，連不上時改用估算值
- 選擇出發日，夜市與市集只抽那天有營業的；可只抽當季景點
- 抽三選一、雨天模式（只抽室內）
- 去過紀錄與「喜歡／普通」評分、「不想去」清單
- 一鍵搜尋出發日當地的市集活動

紀錄與設定只存在各自裝置的瀏覽器裡。營業時間為參考值，出發前請以店家公告為準。
